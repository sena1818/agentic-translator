# 全书非文字审计

日期：2026-11-12。实现：`src/domain/document/nontext_audit.py`（纯规则，不调用模型），
接入点 `src/pipelines/structure/audit.py`，在结构化导出（`StructuredExporter.export_all`）时对整本书运行。

## 查什么

| 类别 | 规则 | 严重度 |
| --- | --- | --- |
| 图片 | 原文与译文的图片路径逐一对应；图片文件能找到 | high |
| 公式 | 行内与独立公式内容逐一相同（空白归一化） | high |
| 代码 | 行内代码与代码块内容逐一相同 | high |
| 表格 | 表格个数、行列数一致；每行单元格中的数字不变（中文数字按数值比） | high |
| 脚注与尾注 | 脚注个数一致；尾注上标编号（含原始 HTML `<sup>N</sup>`）一致；内部链接不断 | high |
| 链接 | 链接地址一致（导出时补的尾注链接除外） | high |
| 编号引用 | 原文"Figure 3 / Fig 3 / Table 1 / Eq. (2) / Section 2.1 / Chapter III"在译文里都能找到对应编号（"图 3""表 1""式 (2)""第 2.1 节""第三章"） | high |
| 顺序 | 图片、独立公式、代码块的先后顺序不变（行内元素随中文语序换位置不算） | medium |
| 标签统一 | 同类标签全书一种译法（"图"与"插图"混用会报） | medium |
| 图注 | 有英文的图注已翻译；原文紧挨着图的"Figure N"图注在译文里仍紧挨着图 | medium |
| 图内文字 | 带英文编号图注、替代文字有英文、或文件名像图表的图片，标记"可能含英文"，**不翻译** | info |

比对以"原文块 ↔ 译文块"组为单位：结构对齐的块逐单元比，定位到该单元第一个段；被人工改过结构的块整块比；
翻译失败、保留原文的块只做原文侧检查。

## 原文问题与翻译问题分开

每条发现带来源：

- **翻译引入**（translation）：原文对得上、译文对不上。进入对照阅读器的问题导航（"非文字审计：…"）。
- **原文本身**（source）：原文引用了书里不存在的图/表/式/节、原文锚点死链、图片文件缺失。阅读器里标"原文问题：…"，
  严重度为 low 的只写入审计文件。判断"存在"只看原文里有编号的对象（图注/表注开头的编号、公式 `\tag`、带编号的标题）；
  某类对象原文里一个编号都没有时不做存在性判断。子图编号（3-2）只要主图（3）存在就算有。
- **仅提示**（notice）：可能含英文文字的图片。

导出时写出 `{stem}.audit.json`，摘要并入 `{stem}.structure.json` 的 `nontext_audit`，
任务质检摘要新增 `nontext_issues`（翻译引入）与 `nontext_source_issues`（原文本身）。

## 注入错误检出

`tests/test_nontext_audit.py` 对同一份含图、公式、表格、代码、脚注、交叉引用的样例分别注入：
丢图、改公式、改表格数字、表格少一行、错编号、断脚注、断尾注上标、改代码、改链接、块顺序调换、图注与图分离、图注未翻译、
同类标签混用，全部检出；原样译文不报翻译问题。

接入 #11 的注入错误基准（`translator-qa-bench --with-audit`，检测器 = 规则质检 + 非文字审计）：

| 错误类型 | 仅规则质检 | 规则质检 + 审计 |
| --- | ---: | ---: |
| 自带段对：改链接地址 | 0 / 3 | 3 / 3 |
| 自带段对：改代码内容 | 0 / 3 | 3 / 3 |
| 自带段对：误报 | 0 / 36 | 0 / 36 |
| 自带段对：种子反例 | 0 / 6 | 2 / 6（改代码、改链接） |
| Cyclonopedia 段对：交换数字 | 1 / 94 | 18 / 94 |
| Cyclonopedia 段对：原样段对上报问题 | 180 / 948 | 181 / 948 |

否定、情态、漏译这类语义错误不在审计范围内（#20 语义质检器负责）。交换数字的提升来自被交换的数字恰好是图号或尾注上标；
正文里的普通数字互换审计看不见。完整表格：[results/qa_injection_audit.md](results/qa_injection_audit.md)。

## Cyclonopedia 全书结果

2026-11-11 基线运行（deepseek-v4.1-flash，242 块），图片目录 `output_final/cyclonpedia/images`：

```bash
python scripts/audit_structured.py data/uploads/<id>_Cyclonopedia.md \
  data/output/baseline_cyclonopedia_2026-11-11/Cyclonopedia.records.json \
  --config config/tokenrhythm.yaml --assets output_final/cyclonpedia/images
```

原文清点：图片 42、带编号的图 27、公式 1、内部链接 3；无表格、无代码、无 pandoc 脚注（尾注标记是原始 HTML 上标，能按 `<sup>N</sup>` 识别的 17 处）。

| 来源 | 发现 | 数量 | 说明 |
| --- | --- | ---: | --- |
| 翻译引入 | 编号引用对不上 | 1 | 原文 OCR 把子图编号写成 "Fig. 3\*1""3\*3"，模型改写成"图 3-1""图 3-3"；属于善意改写，但确实与原文不同，留给人工判断 |
| 原文本身 | 引用了不存在的图 | 2 | "See Fig. 7""Fig. 12"：书中图注编号缺 7、9、12（9 的图注被 OCR 成 "Fir 9"），是转换前就有的问题 |
| 仅提示 | 图片可能含英文 | 27 | 都是带 "Fig. N" 图注的图表，图内文字保持原样 |

图片文件全部找到，图片/公式/尾注上标数量与顺序全部对应，没有图注与图分离，标签译法统一（全书都用"图"）。

审计耗时约 2 秒（整本书，不调用模型）。
